# Working on Illustrated 2.5D Motion

Read `SKILL.md` for the supported workflow. This repository contains reusable
instructions, engine source, fonts and shared procedural sound effects. Keep
individual briefs, brand profiles, reference media, scripts, narration, generated
assets, reviews and final videos in an ignored project workspace.

Preserve the current project's requested style and accepted level of detail.
Brand, language, topic, voice provider and CTA belong to that project. Do not
turn a single example or previous customer's preference into a universal rule.

Keep dependency versions pinned and preserve bundled font license notices.
Before committing, run `python3 scripts/verify_repository.py`; `.gitignore`
does not remove already tracked files. Never include prior production history
or compressed bundles that conceal input or output media.

For engine changes, run the relevant checks and a bounded visual probe in an
ignored workspace. Encoded-frame checks establish technical behavior, not
artistic approval or listening. Leave unobserved review criteria unverified.
Do not send private narration to an external service without authorization.
